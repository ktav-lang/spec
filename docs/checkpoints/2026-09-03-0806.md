## Decisions

- Optional quoted keys design, finalized via explicit user AskUserQuestion answers: **self-escape** (not verbatim — `\"`/`\'`/`` \` `` needed for a segment's own delimiter, reversing an earlier public Habr-reply detail deliberately), **per-segment** quoting (TOML-style: `a."b.c".d` is 3 segments, not 1 atomic quoted whole-key), **canonical writer prefers quoted form** (fixed delimiter `"`) whenever bare form would need to escape a *structural* byte (`.` `:` `,` `{` `}` `[` `]` `(` `)`), a `##`-prefix, or edge whitespace — escaping only `\`/LF/CR/control/DEL does NOT switch the form (quoting buys nothing there), **loud `UnterminatedQuotedKey`** only where a line is definitely a pair line (established Object, or ordinary multi-line pair — NOT inline-pair positions, where an unclosed quote instead makes the enclosing compound itself fail to bracket-balance → `UnterminatedInlineCompound`/`MalformedInlineCompound` instead), **silent Array-item fallback** (no error at all) on the document's still-undecided first content line when it doesn't start with `{`/`[`.

## Decisions

- **Narrow rule, not the uniform "lossless round-trip" rule.** Chose "only a
  redundant leading zero becomes a String" over "any spelling whose canonical
  form differs becomes a String". The uniform rule would have removed
  hex/octal/binary and underscored integer literals from the language; the user
  reviewed the concrete fixture impact table and picked the narrow rule.
- **The § 3.6 grammar stays untouched; § 5.2 carries the exception.**
  `matches_integer_grammar("01234")` still returns true, so the canonical writer
  keeps emitting `zip:: 01234` and canonical output for every existing fixture is
  unchanged. Rejected: changing the grammar (would have moved canonical form and
  broken byte-exact fixtures for no benefit).
- **§ 5.9.6's marker condition re-keyed to the grammar match, not to § 5.2's
  outcome.** Rejected leaving the "would otherwise be reinterpreted as a number"
  wording, which became false for `String("01234")` as an Array item and broke
  the section's "exactly one branch applies" invariant.
- **Appendix A's 0.7.1 entry keeps its `versions/0.7/tests` path** while 27 other
  occurrences were re-pointed to 0.8. Historical entries stay factual — 0.7.1
  genuinely added the file at that path. Same precedent as #284's handling of the
  deleted versions/0.6.
- **The review subagent ran without worktree isolation**, against the standing
  preference, because `isolation: worktree` would have created the worktree in
  the CWD repo (rust) while the review target was spec. Mitigated by an explicit
  read-only-except-the-report instruction and a `git status` check afterwards,
  which confirmed it touched only the report.

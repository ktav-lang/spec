**空 inline 数组项** —— 期望一个项但无任何字节的位置,如两个逗号
之间的体(`[a,, b]`)或开启符紧后(`[, a]`)—— **不是**空 String,
而是 `MalformedInlineCompound` 错误(§ 6.12)。与对的空值
(§ 5.8.2)的不对称是有意的:对的空值有显式键作锚,故「键 X
的空值」意图明确;数组空项无此锚,故视为笔误,而不是有效的空
String 项。

闭合符之前的单个尾部逗号(`[a, b,]`、`{a: 1, b: 2,}`)是公认的
尾部逗号,而**不是**空项(§ 5.8)。

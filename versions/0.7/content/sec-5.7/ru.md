
Четыре последовательности `{}`, `[]`, `()`, `(())` могут появиться
как value-start и обозначают:

| Последовательность | Value |
|----------|-------|
| `{}`     | пустой Object |
| `[]`     | пустой Array |
| `()`     | пустая String |
| `(())`   | пустая String |

Они существуют для того, чтобы пустое составное значение можно было
выразить одной строкой.
